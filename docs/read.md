# 时砂：解压后怎么用

时砂是一款桌面时钟小组件，带备忘提醒、秒表、倒计时和天气。这个压缩包已经附带运行组件，不用另外安装 .NET，也不用注册账号。

这是 **Windows x64 版本**，不适用于 macOS、Linux 或32位 Windows。Windows ARM 电脑尚未验证。

## 打开程序

1. 右键 ZIP，选择“全部解压”。不要直接在压缩包里运行。
2. 把解压出的“时砂便携版”文件夹放到准备长期使用的位置，例如桌面或自己的应用文件夹。程序会在这里保存设置，需要有写入权限。
3. 打开 `app` 文件夹，双击 **时砂.exe**。

请保留完整文件夹，尤其是 `app/runtime`。它是随包附带的运行组件，删掉后程序会打不开。整个文件夹约172 MB。

想放到桌面，可以右键 `app/时砂.exe`，通过“显示更多选项 → 发送到 → 桌面快捷方式”创建快捷方式。也可尝试右键本包里的 `创建桌面快捷方式.ps1`，选择“使用 PowerShell 运行”；如果系统不允许运行脚本，按前一种方法操作即可，无需修改系统执行策略。文件夹搬家后，需要重新创建快捷方式。

## 看时间和安排提醒

默认显示北京时间，采用24小时制。按住顶部“时砂”旁边的空白处，可以把窗口拖到合适的位置。

顶部的小图标依次是：**备忘录、秒表、倒计时、设置**。点击展开，再点一次收起。右边的“−”最小化，“×”把窗口收进右下角托盘。

添加任务时，打开备忘录，写下要做的事，选择日期，再填写时间，例如 `09:00` 或 `21:00`，最后点“添加提醒”。需要每天提醒的任务，勾上“每天重复”。到点会弹窗，并播放一次系统提示音；是否听得到取决于电脑的音量和静音设置。

提醒需要程序保持运行。关闭主窗口后，它仍会留在托盘；双击托盘图标可重新打开，右键可彻底退出。关机、睡眠或彻底退出时，无法当场提醒，下次打开或唤醒后会补提醒。每日任务错过多次时，只补最近一次。

## 秒表和倒计时

秒表可以开始、暂停、继续和重置。倒计时按“小时:分钟:秒”设置，到点弹窗并响铃。

收起面板或关闭到托盘后，计时仍会继续；**彻底退出程序会重置秒表和倒计时**。

## 换时区、语言和天气地区

点齿轮打开设置。选好后，向下滚动，点击“保存设置”。设置页较长，部分选项和保存按钮需要滚动才能看到。

- **时区**同时用于时钟和新任务。例如选洛杉矶后，填09:00就是洛杉矶上午9点。已有任务只换算显示时间，实际提醒时刻不变；每日任务继续按创建时的时区重复。
- **语言**提供简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、葡萄牙语和俄语。自己写的任务不会被自动翻译。
- **天气**按手动选择的地区查询，不申请定位权限，不使用GPS或IP定位。中国支持省／直辖市、市／地区、区／县分级选择，也可停在较高一级；其他国家提供主要城市。

天气卡显示当前天气图标、当地今天的最低至最高温、风向和风级。通常每15分钟刷新。连接失败时显示“天气暂时连不上，稍后再试。”，不保留旧温度和风力数值；5分钟后自动重试。

中国地区名单按需联网加载。加载失败可点“重新加载地区”。名单以数据源现有数据为准；没有下级数据的地区，只能选择已有层级。天气按所选区域的代表点查询，不代表整个省、市或区县每处的天气都相同。

## 保存、备份和退出

### 更换背景（v1.1.0 起）

打开设置，点击“选择背景图”，选择不超过25MB的 JPG 或 PNG。图片会居中裁剪、铺满窗口；拖动“背景明暗”即可预览，调整后自动保存，无需再点“保存设置”。点击“恢复默认背景”可切回纯色。

程序在 `app/data` 保存适合窗口尺寸的图片副本，原图移动后仍可显示。图片不会上传，也不需要额外权限。其他时区、语言和天气选项仍通过“保存设置”保存。

这个分享包**没有附带发送者的任务、设置或地区缓存**，首次打开使用默认设置。

自己的任务和设置会保存在 `app/data`。要换电脑或备份，先从托盘彻底退出，再复制整个“时砂便携版”文件夹，或单独备份 `app/data`。不要用别人的 data 文件夹覆盖自己的任务。

开机启动默认关闭，需要时在窗口底部勾选。它只为当前 Windows 用户添加启动快捷方式；取消勾选会移除。移动或删除程序文件夹前，先取消开机启动。

如果打不开，先确认已经完整解压，`app/runtime`、时砂.exe、时砂.dll 和两个 JSON 配置文件都在，也确认电脑是64位 Windows。仍有问题时，把提示内容发给发送者；不要只拷贝一个 exe 去运行。

## 数据来源与验证范围

天气来自 [Open-Meteo](https://open-meteo.com/)，城市数据来自 [GeoNames / Open-Meteo](https://open-meteo.com/en/docs/geocoding-api)，中国行政区数据来自[阿里云 DataV](https://datav.aliyun.com/portal/school/atlas/area_selector)。天气免费接口用于个人非商业使用。

随包附带 .NET 10.0.11 运行组件。微软许可和第三方声明见 `app/runtime/LICENSE.txt`、`app/runtime/ThirdPartyNotices.txt`。

程序的逻辑、界面布局和天气接口已做检查；未在接收者的电脑、全新 Windows 系统或 Windows ARM 设备上实测。开机启动、睡眠唤醒和扬声器发声也未做跨设备验证。
